## Commit and push from GitHub Desktop

1. Select **Python-Vibe-Coding-Challenge-2627-S1** as the current repository.
2. Review the changed files. Include `main.py`, `scraplab/`, `requirements.txt`, the launch/setup scripts, examples, tests, documentation and README.
3. Enter a summary such as **Add ScrapLab robot engineering game** and click **Commit to main** (or the branch you intend to submit).
4. Click **Push origin**. A commit saves locally; pushing uploads it to GitHub.
5. Open the repository link above. Confirm `main.py` and the `scraplab` folder appear and the page begins with **ScrapLab: Build. Break. Understand.**
6. Submit that repository link. If the repository is private, make sure your teacher has access.

The teacher can download or clone the project, run `setup.cmd`, then `launch.cmd`. GitHub itself does not run this desktop game in the browser. The README contains the assignment fields, setup instructions, screenshots and demonstration links.

The `.gitignore` keeps your virtual environment, recovery draft, named saves and generated lab notes out of the submission. The editable examples and sample measurement reports are included. No push or publication is performed by the setup or launch scripts.
